# Billiard Ball Simulation

This repository contains the Unity assets and configuration for the billiard ball simulation project.

## How to Access

* Download Unity. The project was developed using **Unity 2022.3.22f1**.
* Open Unity Hub and add this repository to your project list.
* Open the project in Unity.

## Functionality

This project explores a simulated violation of causality using billiard balls.

There are two types of balls in the simulation: **regular balls** and **special balls**.

Regular balls behave like normal physical objects. When they collide with something, they react as you would expect according to the laws of physics and bounce away from the impact.

Special balls behave differently. When they collide with regular balls, they are not pushed back. Instead, they continue along their original path while the regular balls react to the collision normally. Special balls also do not collide with each other.

Special balls can additionally be configured to attract or repel regular balls. This allows for more complex interactions and creates a larger apparent violation of causality.

The user can adjust the number of regular and special balls, their movement speed, and various other simulation parameters while the simulation is running.

## Custom Inputs and What They Mean

### Regular Ball Quantity (int)

Controls the number of regular balls in the simulation. This can be adjusted while the simulation is running.

* Suggested range: **[0, 500]**

### Velocity Constant (float)

Controls the velocity of both regular and special balls. The default value is **1**.

The velocity is automatically scaled inversely with the total number of balls, so this parameter generally only needs to be changed when additional adjustments are desired.

* Suggested range: **[0, 5]**

### Diameter Constant (float)

Controls the diameter of both regular and special balls. Similar to the velocity constant, the size is automatically scaled based on the total number of balls.

* Suggested range: **(0, 5]**

### Special Ball Quantity (int)

Controls the number of special balls in the simulation. This can also be adjusted while the simulation is running.

* Suggested range: **[0, 50]**

### Force Constant (float)

Controls the strength of the attraction or repulsion force generated by special balls. This value should not be negative.

The force strength is automatically scaled inversely with the total number of balls, but additional adjustment may still be needed depending on the desired effect.

* Suggested range: **[0, 200]**

### Force Radius (float)

Controls the radius within which a special ball can attract or repel regular balls.

* Suggested range: **[0, 100]**

### Moving Increment (double)

Controls the movement speed of special balls.

Since special balls do not have velocity in the traditional sense, their movement is controlled by an increment applied each frame.

The default value depends on the screen size, so it may vary between devices.

* Suggested range: **[0, 5]**

### Angle Increment (double)

Controls how much special balls can deviate from their original straight path.

* Suggested range: **[0, 5]**

## Keyboard Controls

### Setting Menu

* **Space** — Discard your edits and resume the previous session.
* **Return** — Apply your edits, reset the simulation, and run it again.

> **Important:** Unity's default UI can be a little tricky to work with. After entering a value, make sure to **click somewhere outside of the input box before pressing Return** to apply your changes. Otherwise, the Return key may not register correctly.

### During Simulation

* **Space** — Pause the simulation.
* **-** — Remove a regular ball.
* **+** — Add a regular ball.
* **[** — Remove a special ball.
* **]** — Add a special ball.

### At Any Time

* **Escape** — Quit the program.
